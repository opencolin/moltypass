## v0.9.0-beta — picker + revoke

Reached the council's W5 milestone. Beta-candidate.

- **revoke:** revocation epoch, AbortController registry, `RevokedError`; pre+post-fetch epoch checks in `proxy.ts` so a revoke during an upstream call refuses to surface the response.
- **revoke:** `rotateKey` with crash-safe ordering — write-new + mirror-grants BEFORE delete-old; epoch bump on completion.
- **picker:** Cmd/Ctrl+Shift+M Shadow-DOM crosshair overlay with hover-highlight, Escape cancel, ARIA live announcements.
- **picker:** right-click context-menu "Save selection to Moltypass…" — `info.selectionText` bypasses the system clipboard.
- **picker:** background `picker-bridge` wiring `chrome.commands` + `chrome.contextMenus`.
- Manifest: `contextMenus` permission + `commands` section.

97 tests on main.

## v0.5.0-alpha — security + detector

- **security:** KDF-versioned vault header (`createHeader`/`unlockWithHeader`/`rewrapVault`), AES-GCM payload, PBKDF2(600k) fallback, Argon2id WASM wrapper via hash-wasm.
- **security:** `SECURITY.md` draft — trust model, pre-launch checklist, residual risks.
- **detector:** provider key-creation detector — MutationObserver + shape-regex scanning of dialog subtrees on console.anthropic.com / platform.openai.com / aistudio.google.com.
- **detector:** Shadow-DOM save banner (pure DOM API, no `innerHTML` anywhere).
- **detector:** `src/background/capture.ts` — shape-revalidating capture handler with DI deps; emits `audit.capture`.

## v0.1.0-internal — foundation

- **audit:** IndexedDB log (`moltypass.audit`) with 5 compound indexes, cursor pagination, JSON/CSV export, 365-day retention sweep, legacy chrome.storage.local replay.
- **test-infra:** Vitest + jsdom + fake-indexeddb + fake-chrome harness; CI test-gate (typecheck + vitest + grep-no-keys); `tests/fixtures/synthetic-keys.ts` as the sole allow-listed location for key-shaped strings.
- **proxy:** audit emits on every call (`proxy.ok`/`proxy.error`) with latency + bytes.
